# 🎤 Vocaloid Survival 3D: Мост над водой

Динамичный 2.5D экшен-рогалик в стиле Vampire Survivors с участием Касане Тето, Хацуне Мику и Акиты Неру.

## 🚀 Запуск и обновление на ПК

- **`start_game.bat`** — **Рекомендуемый запуск на ПК**: автоматически синхронизирует папку `music/` с файлом `music/playlist.json (или music/playlist.txt)`, открывает `play.html` в браузере (Firefox / Edge / Chrome) и в фоне отслеживает добавление или удаление треков в папке `music/` прямо во время игры.
- **`play.html`** — Главный файл запуска игры для ПК.
- **`sync_music.bat`** (или `python sync_music.py`) — Мгновенно сканирует папку `music/` и обновляет список `music/playlist.json (или music/playlist.txt)` на диске.
- **`update_game.bat`** — Быстрое обновление игры из репозитория (`git pull`) + автоматическая синхронизация `music/playlist.json (или music/playlist.txt)`.

## 📱 Сборка мобильной версии (`Vocaloid_Survival_Mobile.html`)

Редактируйте только файлы для ПК (`play.html`, `css/styles.css`, `config/balance.json`, `js/*.js`, `images/*`), а затем запустите:
- **`build_mobile.bat`** (или `python build_mobile.py`)

Скрипт автоматически:
1. Соберёт все модули ПК-версии в единый автономный файл **`Vocaloid_Survival_Mobile.html`**.
2. Сожмёт все изображения и спрайты из папки `images/` (с помощью библиотеки `Pillow`: `pip install pillow`).
3. Исключит папку `music/` и музыкальный плеер, чтобы мобильный файл оставался лёгким (~1 МБ).
4. Встроит удобный мобильный интерфейс: плавающий сенсорный джойстик слева, крупную кнопку **⚡ РЫВОК** справа внизу, кнопку сворачивания таблицы статов **📊 Статы** и плавную прокрутку карточек прокачки.

## 🎵 Своя музыка в игре (ПК)

Закиньте любые музыкальные файлы (`.mp3`, `.wav`, `.ogg`, `.flac`, `.m4a`, `.aac`, `.opus`, `.webm`) в папку **`music/`**:
- При запуске через **`start_game.bat`** (или нажатии **`sync_music.bat`** / подключении папки кнопкой **`🎵 Папка music/`** в Edge/Chrome) файл `music/playlist.json (или music/playlist.txt)` автоматически обновляется на диске при добавлении или удалении треков.
- В Главном Меню и во время боя всплывает уведомление об обнаруженных новых или удалённых треках, а музыка играет в случайном порядке.

- Для автоматического сканирования папки `music/` на Windows запустите **`scan_music.bat`** — он мгновенно обновит `music/playlist.json` и `music/playlist.txt` (и продолжит следить за новыми и удалёнными треками на лету).
